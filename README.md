# React Portfolio

Portfolio personal hecho en React durante el bootcamp de Full Stack (Bottega / DevCamp).

## Qué hace
- Página de inicio con los proyectos del portfolio.
- Login: solo la persona autenticada puede gestionar el contenido.
- Gestor de portfolio: crear, editar y borrar proyectos (CRUD) desde la web.
- Consume una API externa con Axios para guardar y leer los datos.

## Con qué está hecho
React, React Router, Axios y SCSS.

## Cómo funciona
Formulario en React → Axios → API → respuesta → React actualiza la pantalla.

## Para arrancarlo en local

```bash
git clone https://github.com/MAIALENSARASOLA/react-portfolio.git
cd react-portfolio
npm install
npm start
```

Se abre en http://localhost:3000
